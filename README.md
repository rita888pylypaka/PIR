# Прогнозування відтоку клієнтів (Customer Churn): базовий MLOps-проєкт
## Мета проєкту
Сформувати стартову структуру MLOps-проєкту, підготувати дані для задачі прогнозування відтоку клієнтів, навчити просту базову модель бінарної класифікації та зафіксувати перший відтворюваний результат у репозиторії.
Базова модель потрібна не для досягнення найкращої якості, а як початкова точка порівняння. Надалі навколо неї будуть будуватися валідація даних, трекінг експериментів, реєстр моделей, API, CI/CD та моніторинг.
Цільова змінна Churn має два значення: клієнт залишився (`No`, 0) або пішов (`Yes`, 1).
## Джерело даних
Датасет Telco Customer Churn (IBM / Kaggle): інформація про клієнтів телекомунікаційної компанії, їхні послуги, контракти, платежі та факт відтоку.
- Файл: data/raw/churn.csv
- Цільова колонка: Churn
- Посилання: (https://www.kaggle.com/datasets/blastchar/telco-customer-churn?resource=download)

## Встановлення залежностей
Створіть і активуйте віртуальне середовище:
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows (PowerShell)
.\.venv\Scripts\Activate.ps1
Встановіть залежності:
pip install -r requirements.txt
## Запуск навчання
python src/train.py
Скрипт завантажує дані, готує ознаки (кодування категоріальних змінних, обробка пропусків), розділяє вибірку на навчальну й тестову, навчає модель та виводить метрики якості.

## Висновок
Створено початкову структуру MLOps-проєкту з відокремленням коду, даних, моделей і документації. Підготовлено дані та навчено базову модель для прогнозування відтоку клієнтів. Отримані метрики (див. вище) слугують точкою відліку: у наступних роботах їх можна буде порівнювати з результатами покращених моделей. Проєкт відтворюваний: після клонування репозиторію, встановлення залежностей і запуску src/train.py можна отримати порівнюваний результат.
